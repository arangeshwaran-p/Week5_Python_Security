
# Week 5 - Python Security Enhancements

## Project Name
Secure User Management System

## Objective
To identify and fix security vulnerabilities in a Python application.

## Features
1. User Registration
2. Secure Login
3. Password Hashing
4. Input Validation
5. SQL Injection Prevention
6. Secure Error Messages

## Technologies Used
- Python
- SQLite
- hashlib
- secrets
- unittest

## How to Run

Run the application:

py app.py

Run security tests:

py -m unittest test_security -v

## Testing
All 5 security tests passed successfully.

## Conclusion
This project demonstrates secure coding practices and
improves application protection against common vulnerabilities.
